# Lumina — AI Video Generator

Premium frontend-only AI video generator UI built with React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and shadcn-style primitives.

## Features

- Landing page with hero, features, how-it-works, benefits, and FAQ
- Drag-and-drop image uploader (1–10 PNG/JPG/JPEG/WEBP)
- Simulated generation progress timeline
- Local video library with preview, download, and delete
- Fully responsive layout with smooth Framer Motion transitions

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Hook Form ready / React Dropzone
- Radix UI primitives (shadcn-style)

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Notes

This app is frontend-only. No backend, authentication, or API calls. Uploads and generation state live in React context.
